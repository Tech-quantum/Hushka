# 💎 هوشکا (Hushka)

**بستری برای کاوش، خلق و مدیریت ایده‌های هوش مصنوعی**

## 📖 درباره پروژه
**Hushka (هوشکا)** یک اپلیکیشن اندروید مدرن برای مدیریت، کاوش و خلق ایده‌های هوش مصنوعی است. این اپ به شما امکان می‌دهد پرامپت‌های خود را ذخیره کنید، با ۴ سرویس هوش مصنوعی چت کنید و از میکروفون هوشمند (آنلاین و آفلاین) استفاده کنید.

### 🎯 قابلیت‌های کلیدی
- 🤖 **چت با AI**: پشتیبانی از Gemini, Groq, OpenAI, DeepSeek
- ⚡ **استریم پاسخ (Typewriter)**: تایپ شدن پاسخ هوش مصنوعی کلمه به کلمه
- 📤 **Share Sheet**: دریافت متن از سایر اپ‌ها (مثل تلگرام) و ارسال مستقیم به چت
- 🎨 **تولید تصویر با AI**: تولید تصویر رایگان و نامحدود با سرویس Pollinations
- 🎤 **جستجوی صوتی ترکیبی**: آنلاین با Groq Whisper یا Gemini + آفلاین با Vosk
- 🎛 **دیالوگ یکپارچه افزودن (+)**: دسترسی به پرامپت جدید و تولید تصویر در ۲ تب
- 🔥 **استریک روزانه (Daily Streak)**: شمارش روزهای متوالی استفاده از اپ با شعله‌ی متحرک و هاله‌ی درخشان
- 📂 **دسته‌بندی نقش‌ها**: بیش از ۴۰ نقش تخصصی (عمومی و روانشناسی)
- 🧠 **متغیرگذاری هوشمند**: تشخیص خودکار متغیرها و باز کردن فرم برای تکمیل آن‌ها
- 💾 **کش هوشمند**: ذخیره‌سازی در RAM و Disk
- 🏷️ **فیلتر پیشرفته تگ‌ها**: انتخاب چندگانه AND/OR
- 🌍 **ترجمه خودکار عنوان‌ها**: به ۴ زبان زنده دنیا
- 📊 **آمار پیشرفته**: نمودارهای دایره‌ای و ستونی
- ✨ **UI/UX مدرن**: Splash Screen، انیمیشن‌ها، Swipe-to-Delete، تم AMOLED
- ⚙️ **دکمه‌ی تنظیمات شناور**: چرخ‌دنده‌ی قابل جابه‌جایی در کل صفحه، هم‌رنگ با تم انتخابی، با موقعیت ماندگار (نگه‌داشتن انگشت روی لوگو هم تنظیمات را باز می‌کند)
- 🔒 **قفل بیومتریک (اختیاری)**: ورود با اثر انگشت یا قفل دستگاه؛ بعد از ۳۰ ثانیه پس‌زمینه دوباره قفل می‌شود

## 🛠 تکنولوژی‌ها
Kotlin 1.9.24 | Compose BOM 2024.09.03 | Room 2.6.1 | Vosk 0.3.47 | Coil | OkHttp

## 🚀 ساخت پروژه
پیش‌نیازها: JDK 17 و دسترسی به اینترنت برای بار اول.

```bash
# مدل‌های صوتی Vosk با Git-LFS نگه‌داری می‌شوند؛ بدون این دستور ZIPها ناقص‌اند
git lfs install && git lfs pull

# بررسی سلامت مدل‌های صوتی (اگر LFS انجام نشده باشد، با پیام واضح خطا می‌دهد)
python3 check_voice_models.py

# تست‌ها و ساخت APK دیباگ
./gradlew testDebugUnitTest
./gradlew assembleDebug
```

> ⚠️ اگر `check_voice_models.py` خطا داد، جست‌وجوی صوتی آفلاین کار نمی‌کند (اپ به‌جای سکوت، پیام خطا نشان می‌دهد).
