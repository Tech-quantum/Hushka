## 📖 درباره پروژه

**Hushka (هوشکا)** یک اپلیکیشن اندروید مدرن برای مدیریت، کاوش و خلق ایده‌های هوش مصنوعی است. این اپ به شما امکان می‌دهد تا پرامپت‌های خود را ذخیره، دسته‌بندی، جستجو و با دیگران به اشتراک بگذارید.

### 🎯 چرا Hushka؟

- 🎨 **رابط کاربری مدرن** با Material 3 و ۵ تم رنگی
- 🌍 **چندزبانه** (فارسی، انگلیسی، عربی، ترکی)
- 🤖 **آنالیز هوشمند** پرامپت با امتیازدهی
- 🌐 **واکشی آنلاین** از مخازن GitHub
- 💾 **دیتابیس محلی** با Room
- 📤 **اشتراک‌گذاری** سریع با هر اپی
- 🎭 **۲۰ شخصیت/نقش** آماده

## ✨ قابلیت‌ها

### 🎨 رابط کاربری
- ۵ تم رنگی: بنفش، قرمز، سبز، آبی، نارنجی
- حالت روشن / تیره / خودکار (بر اساس سیستم)
- طراحی مدرن با Material Design 3
- RTL کامل برای زبان‌های راست‌به‌چپ

### 🌍 چندزبانه
- 🇮🇷 فارسی
- 🇬🇧 English
- 🇸🇦 العربية
- 🇹🇷 Türkçe

### 📝 مدیریت پرامپت
- ➕ افزودن پرامپت جدید
- ✏️ ویرایش پرامپت‌های موجود
- 🗑 حذف با تأیید
- ⭐ علاقه‌مندی‌ها
- 📌 پین کردن
- 🏷️ برچسب‌گذاری
- 📁 دسته‌بندی خودکار

### 🔍 جستجو و فیلتر
- 🔎 جستجوی زنده در متن، عنوان و برچسب‌ها
- 🎤 جستجوی صوتی
- 🏢 فیلتر بر اساس Provider (Anthropic, OpenAI, Gemini, DeepSeek)
- 📁 فیلتر بر اساس دسته‌بندی
- 📊 **۱۰ گزینه مرتب‌سازی**:
  - مرتبط‌ترین
  - پربازدیدترین
  - جدیدترین

  - عنوان

  - بیشترین امتیاز

  - منتخب

### 🎭 سیستم شخصیت/نقش
- ۲۰ نقش آماده (برنامه‌نویس، نویسنده، طراح، پزشک، وکیل و...)
- پیشنهاد خودکار نقش بر اساس دسته‌بندی
- نمایش نقش روی کارت پرامپت

### ✨ آنالیز پیشرفته
- امتیازدهی کیفیت پرامپت (0-100)

  - شفافیت و وضوح (Clarity)

  - ساختار خروجی (Output Contract)
  - متغیرها (Variables)
  - گاردریل‌های امنیتی (Safety)
- توصیه‌های گاردریل هوشکا

### ▶ تست زنده

- فرم پر کردن مقادیر
- پیش‌نمایش زنده
- کپی متن نهایی

- 📤 خروجی JSON

- 📥 درون‌ریزی JSON

### 📊 صفحه آمار

### 🤖 چت با هوش مصنوعی

هوشکا از **۴ سرویس هوش مصنوعی** پشتیبانی می‌کند و می‌توانید روی هر پرامپت دکمه‌ی «اشتراک‌گذاری» را بزنید تا صفحه چت باز شود و پرامپت خودکار به AI ارسال شود.

| سرویس | Emoji | رایگان | کلید از |
|---|---|---|---|
| Google Gemini | 🔵 | ✅ | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |
| Groq | ⚡ | ✅ | [console.groq.com/keys](https://console.groq.com/keys) |
| OpenAI | 🟢 | ❌ | [platform.openai.com/account/api-keys](https://platform.openai.com/account/api-keys) |
| DeepSeek | 🐋 | ❌ | [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys) |

**نحوه فعال‌سازی:**

1. اپ را باز کن → **تنظیمات**
2. تب **🤖 AI** را انتخاب کن
3. سرویس را از Dropdown انتخاب کن
4. کلید API را وارد کن
5. مدل را انتخاب کن (پیش‌فرض کافیست)
6. پیام سبز «✅ کلید API ذخیره شده» باید ظاهر شود
7. حالا روی هر پرامپت، دکمه **اشتراک‌گذاری** را بزن → صفحه چت باز می‌شود

### 💾 کش هوشمند

نتایج واکشی از وب **به مدت ۲۴ ساعت** در حافظه‌ی داخلی ذخیره می‌شوند:

- ⚡ بار دوم واکشی < ۱ ثانیه
- 📴 در حالت آفلاین هم کار می‌کند
- 🔄 دکمه **«به‌روزرسانی»** در دیالوگ واکشی
- 🗑 دکمه **«پاک کردن کش»** در تنظیمات → تب داده‌ها

### ✨ Splash Screen

هنگام باز کردن اپ، صفحه‌ی آغازین با **لوگوی LED درخشان هوشکا** نمایش داده می‌شود:
- چرخه ۶ ثانیه‌ای رنگ‌ها
- انیمیشن ورود (fade + scale)
- نقاط لودینگ پایین

- Fade + Slide Up
- Scale از 0.85 به 1.0
- تأخیر ۴۰ms بین هر کارت
