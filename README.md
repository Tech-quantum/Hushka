## 📖 درباره پروژه

**Hushka (هوشکا)** یک اپلیکیشن اندروید مدرن برای مدیریت، کاوش و خلق ایده‌های هوش مصنوعی است. این اپ به شما امکان می‌دهد تا پرامپت‌های خود را ذخیره، دسته‌بندی، جستجو و با دیگران به اشتراک بگذارید.

### 🎯 چرا Hushka؟

- 🎨 **رابط کاربری مدرن** با Material 3 و ۵ تم رنگی
- 🌍 **چندزبانه** (فارسی، انگلیسی، عربی، ترکی)
- 🤖 **آنالیز هوشمند** پرامپت با امتیازدهی
- 🌐 **واکشی آنلاین** از مخازن GitHub
- 💾 **دیتابیس محلی** با Room
- 📤 **اشتراک‌گذاری** سریع با هر اپی
- 🎭 **۲۰ شخصیت/نقش** آماده

## ✨ قابلیت‌ها

### 🎨 رابط کاربری
- ۵ تم رنگی: بنفش، قرمز، سبز، آبی، نارنجی
- حالت روشن / تیره / خودکار (بر اساس سیستم)
- طراحی مدرن با Material Design 3
- RTL کامل برای زبان‌های راست‌به‌چپ

### 🌍 چندزبانه
- 🇮🇷 فارسی
- 🇬🇧 English
- 🇸🇦 العربية
- 🇹🇷 Türkçe

### 📝 مدیریت پرامپت
- ➕ افزودن پرامپت جدید
- ✏️ ویرایش پرامپت‌های موجود
- 🗑 حذف با تأیید
- ⭐ علاقه‌مندی‌ها
- 📌 پین کردن
- 🏷️ برچسب‌گذاری
- 📁 دسته‌بندی خودکار

### 🔍 جستجو و فیلتر
- 🔎 جستجوی زنده در متن، عنوان و برچسب‌ها
- 🎤 جستجوی صوتی
- 🏢 فیلتر بر اساس Provider (Anthropic, OpenAI, Gemini, DeepSeek)
- 📁 فیلتر بر اساس دسته‌بندی
- 📊 **۱۰ گزینه مرتب‌سازی**:
  - مرتبط‌ترین
  - پربازدیدترین
  - جدیدترین
  - علاقه‌مندی‌ها
  - عنوان
  - دسته‌بندی
  - سریع‌ترین پاسخ
  - بیشترین امتیاز
  - پیشنهاد کاربران
  - منتخب

### 🎭 سیستم شخصیت/نقش
- ۲۰ نقش آماده (برنامه‌نویس، نویسنده، طراح، پزشک، وکیل و...)
- پیشنهاد خودکار نقش بر اساس دسته‌بندی
- نمایش نقش روی کارت پرامپت

### ✨ آنالیز پیشرفته
- امتیازدهی کیفیت پرامپت (0-100)
- تحلیل ۵ بخش:
  - شفافیت و وضوح (Clarity)
  - تعریف نقش (Role)
  - ساختار خروجی (Output Contract)
  - متغیرها (Variables)
  - گاردریل‌های امنیتی (Safety)
- توصیه‌های گاردریل هوشکا

### ▶ تست زنده
- تشخیص خودکار متغیرهای پرامپت (مثل `[SUBJECT]`)
- فرم پر کردن مقادیر
- پیش‌نمایش زنده
- کپی متن نهایی

### 🌐 واکشی از وب
- دانلود ۲۱۶۹ پرامپت از مخزن `awesome-chatgpt-prompts`
- انتخاب چندتایی
- درون‌ریزی به دیتابیس

### 📄 پشتیبان‌گیری
- 📤 خروجی JSON
- 📝 خروجی Markdown
- 📥 درون‌ریزی JSON

### 📊 صفحه آمار
- تعداد کل پرامپت‌ها
- تعداد علاقه‌مندی‌ها
- تعداد پین‌شده‌ها
- کیفیت داده (درصد دسته‌بندی، برچسب، نقش)
- پرامپت به تفکیک دسته
- پرکاربردترین پرامپت‌ها

### 📤 اشتراک‌گذاری
- Share Intent استاندارد
- ارسال به WhatsApp, Telegram, Gmail, ChatGPT, و...

### 🔄 نشانگر اتصال
- آیکون ابر با نقطه سبز (آنلاین)
- آیکون ابر با نقطه قرمز (آفلاین)
- چرخش در حین آپدیت
